## 📂 Task Breakdown & Overview

This internship program comprises tasks ranging from beginner to expert levels:

* **Task 1: Basic HTML Page**
  * Created a structured HTML document using semantic tags (`<html>`, `<head>`, `<body>`), headings (`<h1>`, `<h2>`), paragraphs, and images.
* **Task 2: Styling with Inline CSS**
  * Applied inline styles directly within HTML elements to understand the fundamentals of CSS properties like font color, size, and background colors.
* **Task 3: Responsive Design**
  * Implemented CSS Media Queries (`@media`) in a separate stylesheet (`styles.css`) to ensure the webpage layout adapts smoothly across different screen sizes (mobile, tablet, desktop).
* **Task 4: Interactive Button & JavaScript**
  * Added interactivity by integrating JavaScript event listeners (`addEventListener`) to dynamically trigger background color changes upon button clicks.
* **Task 5: API Integration**
  * Fetched live data from a public API (`JSONPlaceholder`) using JavaScript's `fetch()` method and dynamically updated the DOM to display user profiles.
* **Task 6: Form Styling and Validation**
  * Designed a user-friendly form and implemented robust client-side validation using JavaScript to check for empty fields, proper email formats, and password length constraints.
* **Task 7: Component-Based Styling (Bootstrap)**
  * Utilized the Bootstrap framework to build a responsive, professional layout featuring a navigation bar, header banner, and styled cards.
* **Task 8: Introduction to CSS Preprocessing (Sass)**
  * Explored modern CSS preprocessor concepts including variables, nesting, and modular stylesheet organization.
